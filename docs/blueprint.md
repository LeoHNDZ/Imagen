# **App Name**: Scripter Image

## Core Features:

- Script Input: Accept script text as input via a text box.
- Image Style Input: Accept a description of the desired image style via a separate text box.
- Scene Analyzer Tool: Use an AI tool to process the script and identify key scenes or phrases.
- Image Generation: Generate images based on the script analysis and the user-specified style.
- Image Display: Display the generated image alongside the corresponding script section.
- Configuration: Basic parameters, such as default styles, output formats, default model.

## Style Guidelines:

- Primary color: Dark gray (#333333) for a modern, sophisticated look.
- Background color: Black (#000000) for a visually striking dark theme.
- Accent color: Electric blue (#7DF9FF) to highlight important elements and provide a vibrant contrast.
- Body text: 'Roboto' (sans-serif) for clear and readable script display on dark backgrounds.
- Headline Text: 'Montserrat' (bold sans-serif) for short title descriptions to contrast body text.
- Use simple, clear, and glowing icons (with a blue hue) for actions like 'generate', 'save', and 'settings'.
- Clear separation of script input, style input, and image display areas with a focus on readability in a dark theme.
